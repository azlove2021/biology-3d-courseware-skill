# 基因的表达：转录与翻译 · 3D 互动课件

人教版 2019 必修2《遗传与进化》第4章第1节。玻璃拟态教学驾驶舱样板课。

- 主线问题：DNA 在细胞核里，蛋白质在细胞质里，基因的指令怎样传过去？
- 因果链：DNA → mRNA → 核糖体 → 肽链 → 蛋白质
- 9 步，最后一步为考核
- 单页 + 本地 `libs/three.min.js`，双击离线可用

## 打开方式

双击 `index.html` 即可，无需服务器、无需构建。

- 依赖：`libs/three.min.js`（three.js r128，已随包提供）
- 离线验证通过：断网后仍可完整运行
- 无任何外链资源

## 操作

| 操作 | 方式 |
|---|---|
| 上一步 / 下一步 | 底部按钮，或 `← →` |
| 跳步 | 点顶部步骤条，或 `1–9` |
| **旋转场景** | 按住左键拖拽 |
| **缩放** | 滚轮，或底部视角条 `−` `＋` |
| **平移** | 右键拖拽，或 `Shift` + 拖拽 |
| **点选结构** | 单击 DNA / mRNA / 核糖体 / tRNA / 肽链 / 核孔 / 细胞核 / RNA 聚合酶 → 高亮 + 信息卡 |
| **聚焦结构** | 双击结构，或点右栏「结构速查」里的按钮 |
| **回预设视角** | `R`，或视角条 `⟲` |
| **折叠左栏（讲解）** | 顶栏「讲解」或 `H` |
| **折叠右栏（中控）** | 顶栏「中控」或 `J` |
| **影院模式** | 顶栏「影院」或 `F`（左右栏 + 顶栏 + 底栏全隐）；`Esc` 退出 |
| 浏览器全屏 | `Shift` + `F`，或影院胶囊 `⛶` |
| 揭示结论 | 左栏「揭示结论」 |
| 演示速度 | 右栏「演示速度」滑块 |
| 碱基 / tRNA / 核糖体 | 右栏开关 |
| 考核 | 右上「检测」或 `Q` |
| 语音开关 | 右上「语音」或 `V` |
| 自动讲课 | 底部「自动讲课」 |

> 视角规则：进入新步骤会自动回到该步预设机位；一旦你手动拖拽/缩放，本步内不再自动改机位，直到切步或按 `R`。

## URL 参数

```
index.html?t=6             # 直接跳到第 7 步（翻译延伸）
index.html?voice=0         # 关闭语音
index.html?simple=1        # 简洁模式
```

`t` 范围 0–8；`NaN` 按 0，负数/超界自动夹紧。
