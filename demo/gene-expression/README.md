# 基因的表达：转录与翻译 · 3D 互动课件

人教版 2019 必修2《遗传与进化》第4章第1节。玻璃拟态教学驾驶舱样板课。

- 主线问题：DNA 在细胞核里，蛋白质在细胞质里，基因的指令怎样传过去？
- 因果链：DNA → mRNA → 核糖体 → 肽链 → 蛋白质
- 9 步，最后一步为考核
- 单页 + 本地 `libs/three.min.js`，双击离线可用

## 打开方式

双击 `index.html` 即可，无需服务器、无需构建。

- 依赖：`libs/three.min.js`（three.js r128，已随包提供）
- 离线验证通过：断网后仍可完整运行
- 无任何外链资源

## URL 参数

```
index.html?t=6             # 直接跳到第 7 步（翻译延伸）
index.html?voice=0         # 关闭语音
index.html?simple=1        # 简洁模式
```

`t` 范围 0–8；`NaN` 按 0，负数/超界自动夹紧。
