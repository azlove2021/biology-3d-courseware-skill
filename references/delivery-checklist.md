# 交付前检查清单（v1.2 驾驶舱）

逐条勾选，不跳项。阻断项不过，不得交付。

## A. 立项与配置

- [ ] 目录为 `NNN_project_项目名/`，自包含，未散放
- [ ] 已查点子计划表，确认编号 / 类型 / 优先级
- [ ] `courseware-profile.json` 存在：`type` / `layout` / `theme` / `bundle` / `voiceMode` / `quantityChart` / `publishMode`
- [ ] 任何豁免（如 `voiceMode: disabled`）都写明了理由
- [ ] `layout` 为 `cockpit`（v1.2 默认）；`legacy` 仅用于维护旧课件

## B. 取材与专业性

- [ ] 按 `local-config.md` 的优先级取材，未硬编码本机路径
- [ ] 教材依据到**小节级**；不确定的已标"待核实"
- [ ] 主线问题 1 句；因果链 3–5 环
- [ ] 步骤 6–9 步，最后一步固定「考核」
- [ ] 每步都有：问句 / 动手 / 应该看到 / 结论 / 要点 / 易错点 / 考点
- [ ] 未编造页码、显微尺寸、实验数据
- [ ] 术语符合 `terms.md`
- [ ] 页面有「示意 · 非真实比例」；底栏有示意声明

## C. 数据（单一数据源）

- [ ] 有 `<script type="application/json" id="courseware-data">`
- [ ] 每步有 `id/name/short/group/summary/narration/events/scope/warning/question/source`
- [ ] 有 `counts`（染色体类）或 `metrics`（连续指标），不能两者都空
- [ ] `id` 不重复；`metrics` 每步 key 集合一致，value 为数字
- [ ] `counts`：3 个非负整数；染色单体为 0 或 2×染色体；`cells` ≥ 1
- [ ] README 步骤表与数据逐行一致
- [ ] 曲线由 `STAGES` / `DATA.stages` 派生，x/y 轴未写死

## D. 驾驶舱七区

- [ ] ① 顶栏：标题 + 副标题 + 主线问题 + 运行状态 + 得分 + 检测/玩法/全屏/语音
- [ ] ② 因果链：3–5 个 chip + 箭头 + 每格一句解释；当前环节高亮
- [ ] ③ 步骤条：6–9 步编号 + 短标题；当前步蓝色胶囊；已完成绿点；可点击跳步
- [ ] ④ 左栏本步：面包屑 + 问句 + 场景说明 + 动手 + 应该看到 + 揭示结论/复位 + 要点/易错点/考点 + 单元 tab
- [ ] ⑤ 中央 3D：浅色场景 + 浮动标签 + 方程式卡 + 每步机位
- [ ] ⑥ 右栏中控台：2–4 个读数 + 2–4 个滑块 + 迷你曲线 + 参考工况/复位 + 图例
- [ ] ⑦ 底栏：上一步/下一步 + 第 X/N 步 + 示意声明 + 快捷键
- [ ] 一屏放下，无页面滚动；中央 3D 至少 560px 宽

## E. 3D 与交互

- [ ] 程序化建模，不依赖外部模型文件
- [ ] 对象命名并挂 `userData`
- [ ] 浮动标签投影正确，不压在面板下
- [ ] 相机每步一个预设，过渡 0.8–1.2s，不瞬移
- [ ] 滑块实时改变 3D 与读数，不是只改数字
- [ ] 开关（碱基/tRNA/核糖体等）真的改变 3D
- [ ] 键盘 `← →`、`1–9`、`Q`、`F`、`Esc` 可用
- [ ] 像素比上限 2；移动端帧率可接受

## F. 语音（五态）

- [ ] 使用 `voiceState`：`pending / speaking / ended / cancelled / error`
- [ ] 每条语音有 `voiceToken`，过期回调被忽略
- [ ] 只有 `ended` 才允许进入下一步（或自动讲课）
- [ ] 没有用 `if(!speaking)` 判断结束
- [ ] 切步/关闭语音/复位都调用 `cancelVoice()`
- [ ] `onerror` 有 800ms 兜底；另有总超时
- [ ] 首次点击页面后才发声
- [ ] 无中文语音时有提示，不静默失败
- [ ] `?voice=0` 可关闭

## G. 离线与运行

- [ ] 单 HTML 内联 three.js，或本地 `libs/`；二者都能断网运行
- [ ] HTML/CSS 无外链（CDN 只作为 JS 兜底）
- [ ] **断网后**双击仍可完整运行
- [ ] `node --check` 内联脚本通过
- [ ] `check_courseware.py` 阻断项为 0
- [ ] 改过模板/脚本后跑过 `tests/test_checker.py`
- [ ] 可选：`smoke_test.py --offline` 通过，截图已抽查

## H. 文档

- [ ] `README.md`：打开方式、步骤表、操作表、URL 参数、离线/联网说明
- [ ] `修改记录.md`：改了什么、为什么、验证记录、已知简化
- [ ] `preview.png`：首屏截图，清晰可辨
- [ ] README 与课件实际行为一致（步骤、参数、语音）

## I. 发布

- [ ] 按 `publishMode` 执行；`local` 时不擅自建远程仓库
- [ ] 发布前扫描密钥、个人信息、内部文件、未授权素材
- [ ] 用户已授权公开；私有仓库未被擅自改公开
- [ ] 已告知哪些内容上传、哪些留在本地
- [ ] Pages 验证主页 / 样板课 / 静态资源均 200

## J. 人工验收（五层）

- [ ] 数据：数值、步骤顺序、统计口径正确
- [ ] 结构：七区齐全；3D 对象数量/层级正确
- [ ] 过程：每步运动符合生物学过程
- [ ] 界面：画面、旁白、读数指向同一步
- [ ] 教学：学生能从画面看出要理解的机制
