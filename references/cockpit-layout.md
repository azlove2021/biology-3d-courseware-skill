# 教学驾驶舱版式

替代旧版「顶部 header + 左舞台 + 右六块面板 + 底部时间轴」。新标准是**一屏驾驶舱**：老师按「下一步」就能从头讲到尾。

## 1. 七个区域

```
┌──────────────────────────────────────────────────────────────┐
│ ① 顶栏：标题 · 副标题 · 主线问题 · 状态 · 得分 · 检测/玩法/全屏 │
│    ② 因果链：A → B → C → D → E（每格一句解释）                 │
├──────────────────────────────────────────────────────────────┤
│ ③ 步骤条：①─②─③─④─⑤─⑥─⑦─⑧─⑨（当前步高亮）                    │
├───────────────┬──────────────────────────────┬───────────────┤
│ ④ 左栏 本步    │        ⑤ 中央 3D 舞台         │ ⑥ 右栏 中控台  │
│ 问句→动手→结论 │  浮动标签 / 方程式卡 / 3D 场景 │ 读数 / 滑块 / 图 │
├───────────────┴──────────────────────────────┴───────────────┤
│ ⑦ 底栏：‹ 上一步 · 第 X / N 步 · 下一步 › · 示意声明 · 快捷键   │
└──────────────────────────────────────────────────────────────┘
```

尺寸（1600×900 参考）：四周 10px；顶栏 78px；步骤条 46px；底栏 52px；左栏 `clamp(320px,22vw,404px)`；右栏 `clamp(300px,20.5vw,348px)`；中央 3D 至少 560px 宽。

## 2. 各区域必备内容

### ① 顶栏
- 左侧：小徽标（课程编号/学科）+ 课程标题 + 副标题（一句话讲清机制）
- 中间：`主线问题` 紫色 chip + 问题全文（12px，可截断）
- 右侧：`运行中` 绿点 + `得分 0` + `检测 Q` + `玩法` + `全屏 F` + `设备名 N`

### ② 因果链
- 3–5 个概念 chip，箭头连接
- 每个 chip：小圆点 + 名称 + 下方一句 10–11px 解释
- 已完成/当前/未到三态：绿色/蓝色/灰色
- 例：`静息 K⁺外流·内负外正 → 兴奋 Na⁺内流·内正外负 → 传导 局部电流·向前 → 突触 递质·单向较慢`

### ③ 步骤条
- 6–9 步，编号圆点 + 短标题（2–6 字）
- 当前步：蓝色渐变胶囊 + 白字；已完成：绿底圆点；未到：灰
- 可点击跳步；键盘 `1–9` 跳步，`← →` 翻步

### ④ 左栏「本步」
固定顺序，缺一不可：
1. `本步` 标签 + 面包屑「问句 → 动手 → 结论 + 要点 + 考点」
2. 步骤号（20px 蓝）+ 问句（加粗）
3. 场景说明（12px 灰，说明当前 3D 在看什么）
4. `动手试一试` + 状态 chip（还没做/已完成）
5. 操作指令（做什么）
6. `应该看到：` 浅蓝底块（观察结果）
7. 按钮：`揭示结论`（主按钮）+ `复位本步`
8. 底部单元 tab：① ② ③（切换 3D 场景的子单元）

### ⑤ 中央 3D 舞台
- 浅色渐变背景 + 3D 模型
- 浮动标签（白胶囊）指向关键结构
- 底部中央「方程式 · 条件」玻璃卡（1–2 行公式/条件）
- 相机按步骤切换预设机位，过渡 0.8–1.2s

### ⑥ 右栏「中控台」
- 标题 `中控台` + 一句「拖一个滑块，看全局的代价」
- 2–4 个读数卡（大数字 + 单位 + 小字说明）
- 2–4 个滑块（标签 + 当前值 + 刻度说明）
- 1 个迷你图（曲线/柱状，高 80–100px）
- 2 个预设按钮：`参考工况` + `停车/复位`（危险操作红色描边）

### ⑦ 底栏
- 左：`‹ 上一步`；中：`第 X / N 步`；右：`下一步 ›`
- 下方小字：`示意声明：……` + 快捷键说明
- 声明必须写清：示意放大、数值为课件设定、时程已放慢、简化假设

## 3. 内容结构

每门课 6–9 步，最后一步固定为**考核**：

| 步 | 作用 | 左栏问句示例 |
|---|---|---|
| 1 | 认识现场/装置 | 先看什么？怎么操作？ |
| 2–4 | 建立核心概念 | 为什么必须这样？如果不呢？ |
| 5–7 | 机制/过程/变量 | 谁在动？谁提供能量？ |
| 8 | 迁移/应用/异常 | 换成另一种条件会怎样？ |
| 9 | 考核 | 3 道选择题，覆盖前 8 步 |

- 每步必须能回答：**问句 → 动手 → 结论 + 要点 + 考点**
- 每步只讲一个因果环节；不要在一屏塞两个机制
- 主线问题贯穿全课，最后一步回到它
- 教材依据写在小节级（如 `必修2 第4章第1节`），不写页码除非可核对

## 4. 交互契约

- `下一步/上一步` 必须改变：3D 机位、左栏文案、右栏读数、步骤条高亮
- 滑块必须实时改变 3D 与读数；不允许只改数字
- 迷你图必须随步骤/滑块更新；不允许贴图写死
- 相机：每步一个预设（位置 + 目标点），过渡用缓动；不要瞬移
- 语音：每步一段旁白，使用五态状态机；`讲完再进下一步`
- 考核：至少 3 题，答错给解析；得分显示在顶栏
- 键盘：`← →` 翻步、`1–9` 跳步、`Q` 检测、`F` 全屏、`Esc` 回中控台

## 5. 组件配方

| 组件 | 用法 |
|---|---|
| 步骤胶囊 | `.step` / `.step.on` / `.step.done`，见 `theme-tokens.md` |
| 因果 chip | `.chip` + `.dot`，单元色用 `--uc` |
| 读数卡 | `.readout`，大数字用 `--num` + tabular-nums |
| 滑块 | `.sl` + `.trk`，填充色用 `--uc`/`--heat` |
| 浮动标签 | `.tag`，投影到 3D 坐标，避让重叠 |
| 方程式卡 | `.eqb`，玻璃卡 + 12px 圆角，居中底部 |
| 单元 tab | 左栏底部，3 个圆点 + 名称，当前单元用 `--uc` |
| 结论块 | 浅蓝底 `--sci-8`，左侧 3px `--sci` 竖线 |
| 警示块 | 浅橙底 `--warn-10`，左侧 3px `--warn` 竖线 |

## 6. 响应式与降级

- ≥1400px：左右栏全宽，中央 3D 最大
- 1100–1400px：左右栏收窄到 `clamp` 下限，字号不变
- <1100px：左栏折叠为抽屉（`☰ 本步`），右栏收为底部抽屉；中央 3D 保持 ≥ 55vh
- <760px：顶栏只留标题 + 菜单；步骤条横向滚动；底栏保留上一步/下一步
- 低帧率：`body.lowfps` 去掉 `backdrop-filter`，面板改 `--glass-solid`
- 所有交互必须有 `:focus-visible` 轮廓（`2px solid var(--sci)`，offset 2px）

## 7. 验收清单

- [ ] 一屏内放下七个区域，无页面滚动
- [ ] 顶栏有主线问题；步骤条 6–9 步且最后一步是考核
- [ ] 左栏具备「问句 → 动手 → 应该看到 → 揭示结论 → 复位」完整链路
- [ ] 右栏有读数 + 滑块 + 迷你图，且随步骤/滑块变化
- [ ] 中央 3D 有浮动标签与方程式卡
- [ ] 底栏有上一步/下一步、第 X/N 步、示意声明、快捷键
- [ ] 玻璃面板 token 与 `theme-tokens.md` 一致
- [ ] 键盘 `← →`、`1–9`、`Q`、`F`、`Esc` 可用
- [ ] 断网可运行，无外链
- [ ] 语音讲完一段才进入下一步

## 8. 与旧版六块面板的映射

| 旧版 | 新版 |
|---|---|
| 阶段讲解 | 左栏「本步」问句 + 场景说明 + 应该看到 |
| 实时读数 | 右栏读数卡 |
| 数量曲线 | 右栏迷你图 |
| 本时期要点 | 左栏「揭示结论」后的要点 |
| 易错点 | 左栏警示块 / 右栏异常读数 |
| 观察任务 | 左栏「动手试一试」+「应该看到」 |
| 顶部阶段导航 | 步骤条 + 因果链 |
| 底部时间轴 | 底栏上一步/下一步 + 步骤条跳步 |
