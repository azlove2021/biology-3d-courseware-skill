# 运行契约：离线、URL 参数、浏览器验证

## 1. 离线契约

「本地 libs + CDN 兜底」可以共存，但验收标准必须明确：

| 模式 | 要求 |
|---|---|
| 离线模式 | **不依赖任何网络请求**；断网后所有必需功能可用 |
| 联网预览 | 允许 CDN 兜底；但不能用"CDN 能加载"证明离线通过 |

实现要求：

1. `libs/three.min.js` 必须随项目提供，优先加载本地
2. CDN 只能作为 **JS 兜底**（`if(!window.THREE)` 后注入），不能写成无条件的 `<script src="https://...">`
3. HTML / CSS 中不得出现外链字体、图片、音频、脚本、样式
4. 本地关键资源缺失时，页面显示清晰错误提示，而不是白屏
5. README 必须区分「离线验证通过」与「联网预览通过」

离线验收必须**真的断网**（或阻断 http(s) 请求）后再打开，不能只看本地文件存在。

## 2. URL 参数契约

只写**已经实现**的参数。文档、代码、检查清单三处必须一致。

| 参数 | 含义 | 取值 / 默认 | 非法值处理 | 适用范围 |
|---|---|---|---|---|
| `t` | 定位阶段 | `0 .. N-1`，默认 `0` | `NaN`→0；负数/超界→夹紧 | 过程型 |
| `voice` | 语音开关 | `1` / `0`，默认 `1` | 其他值按 `1` | 有语音 |
| `simple` | 简洁模式 | `1` / `0`，默认 `0` | 其他值按 `0` | 所有 |
| `xo` | 交叉互换 | `1` / `0`，默认 `0` | 其他值按 `0` | 仅相关课件 |
| `arr` | 排列方式 | `0` / `1`，默认 `0` | 其他值按 `0` | 仅支持切换 |
| `panel` | 移动端面板 | `1` / `0`，默认 `0` | 未实现就不要写进文档 | 实现后 |

必须夹紧：

```js
t = Math.min(N - 1, Math.max(0, parseFloat(q.get('t')) || 0));
```

## 3. 浏览器冒烟测试（可选）

`node --check` 只验证语法，不证明页面能跑。交付前建议跑一次：

```bash
python scripts/smoke_test.py "<课件.html>" --offline
```

检查项：

1. 页面能打开，无 `pageerror` / `console.error`
2. `canvas` 存在且宽高 > 0
3. 点击"下一阶段"后阶段名变化
4. 播放/暂停可点击
5. 截图到 `_smoke/`，供人工抽查
6. `--offline` 时阻断所有 http(s) 请求后重载，`canvas` 仍正常

未安装 Playwright 时脚本输出 `SKIP` 并返回 0，不阻断交付。安装：

```bash
pip install playwright
playwright install chromium
```

## 4. 检查通过 ≠ 科学正确

自动化只能证明"结构、数据、运行"三层。以下必须人工或场景断言：

| 层次 | 检查内容 | 谁来做 |
|---|---|---|
| 数据检查 | 数值、阶段顺序、统计口径 | 脚本 + 人工 |
| 结构检查 | 对象数量、层级、身份 | 脚本 + 人工 |
| 过程检查 | 各阶段运动是否符合生物学过程 | 人工 / 截图断言 |
| 界面检查 | 画面、旁白、数据是否指向同一阶段 | 人工 |
| 教学检查 | 学生能否从画面看出机制 | 教师 |

数字正确不代表模型正确：染色体数对了，不代表同源染色体真的分离了。
