# 阶段数据结构与数量自检

## 1. 原则

**数据先行**：先把阶段数组写完整、把数量表算通，再写 3D 与交互。数字不通，动画一定错。

- 图表曲线、右侧读数、时间轴刻度、旁白里的数字，**全部来自同一个数组**
- 不允许在 HTML 或绘图函数里另写一套数字
- 阶段索引 `t` 为整数；阶段间形变只用于过渡，不承载新数字

## 2. STAGES 字段

```js
const STAGES = [
  {
    n: '间期 · 复制前',        // 阶段名（21px 标题）
    short: '复制前',           // 时间轴按钮短名
    phase: '减数分裂前的间期',  // 阶段归类（用于顶部 tag）
    s: 'DNA 尚未复制，每条染色体只含 1 条 DNA',
    v: '这是减数分裂开始前的间期。此时 DNA 还没有复制，细胞里有 4 条染色体，每条染色体只含 1 个 DNA 分子，没有姐妹染色单体。',
    f: [                       // 本时期要点（折叠区）
      '染色体呈细长的染色质丝',
      '核膜、核仁仍然存在'
    ],
    c: [4, 4, 0],              // [染色体, DNA, 染色单体]
    cells: 1,                  // 细胞数
    scope: '每个细胞',          // 统计口径（必填）
    cn: '染色体数 = DNA 数 = 4，无染色单体',  // 读数卡下方说明
    w: '不要把“染色质”和“染色体”当成两种物质，它们是同一物质在不同时期的形态。', // 易错点
    q: '观察：此时能找到四分体吗？为什么？',   // 观察任务
    tb: '必修2 第2章 第1节'     // 教材依据（小节级，必填）
  },
  /* ... */
];
```

### 字段约束

| 字段 | 必填 | 说明 |
|---|---|---|
| `n` | ✅ | 阶段全名，与教材一致 |
| `short` | ✅ | ≤4 字，时间轴按钮用 |
| `phase` | ✅ | 大阶段归类，用于分组与配色 |
| `s` | ✅ | 一句话概括，≤30 字 |
| `v` | ✅ | 旁白，60–120 字，口语化，读完约 12–20 秒 |
| `f` | ✅ | 2–4 条要点 |
| `c` | ✅ | `[染色体, DNA, 染色单体]`，整数 |
| `cells` | ✅ | 当前统计的细胞数 |
| `scope` | ✅ | 统计口径，不能空 |
| `cn` | ✅ | 数量关系的一句话解释 |
| `w` | ✅ | 易错点，必须具体，不写“注意审题”这类空话 |
| `q` | ✅ | 观察任务，要能在画面上找到答案 |
| `tb` | ✅ | 教材小节，如 `必修2 第2章 第1节`；不确定就问用户，不臆造页码 |

## 3. 数量自检表（README 必附）

```markdown
| # | 阶段 | 染色体 | DNA | 染色单体 | 细胞数 | 统计口径 | 教材依据 |
|---|---|---|---|---|---|---|---|
| 1 | 间期·复制前 | 4 | 4 | 0 | 1 | 每个细胞 | 必修2 第2章第1节 |
| 2 | 间期·复制后 | 4 | 8 | 8 | 1 | 每个细胞 | 必修2 第2章第1节 |
```

规则：
- 行数 = 阶段数，一行不漏
- 「后期」着丝粒分裂后，染色体数暂时加倍、染色单体归零，必须单独成行
- 「末期」胞质分裂后细胞数变化，`scope` 必须跟着改
- 表格里的数字必须与 `STAGES[i].c` 完全一致
