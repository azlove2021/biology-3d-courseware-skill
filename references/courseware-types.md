# 四类课件范式

共用外壳（主题 / 布局 / 语音 / 面板 / 发布），差异在 3D 场景与交互。开工前先对号入座。

各类型的推荐 `courseware-profile.json` 见 `courseware-profile.md`。可豁免项不是"省事"，是"教学目标不需要"，关闭需写明理由。

| 类型 | 必开 | 可豁免（需理由） |
|---|---|---|
| `process` | 阶段数组、时间轴、播放/单步、数量曲线 | 无（过程型不建议关曲线） |
| `anatomy` | 爆炸视图、剖切、点选高亮、部件标签 | 数量曲线、阶段数组 |
| `experiment` | 自变量、因变量、对照组、结论区 | 阶段数组、时间轴 |
| `comparison` | 双场景、阶段映射、差异高亮、对比表 | 无 |

## 1. 时间轴 / 过程型

**代表**：S-01 减数分裂、光合作用过程、分泌蛋白合成运输、细胞周期

**必备**
- 阶段数组（见 `stage-schema.md`），整数索引
- 顶部阶段导航（按大阶段分组）+ 底部时间轴
- 播放 / 暂停 / 上一 / 下一 / 单步
- 数量曲线（至少一条随阶段变化的量）
- 每阶段旁白 + 易错点 + 观察任务

**交互**
- 拖拽旋转、滚轮缩放
- 点击结构高亮（如点击染色体高亮同源染色体）
- 关键过程可开关（交叉互换、自由组合排列）

**坑**
- 阶段间数字不一致（复制前后压成一段）
- 图表写死点数
- 语音与动画各跑各的（必须 hold→morph）

## 2. 结构 / 解剖型

**代表**：细胞器、细胞核、心脏结构、花的结构、DNA 双螺旋

**必备**
- 爆炸视图（部件沿法线散开）+ 复位
- 剖切面（半透明或裁剪平面）
- 点选部件 → 右侧显示名称、功能、易错点
- 部件标签（投影 DOM，带引线更佳）
- 层级缩放：整体 → 系统 → 单个结构

**交互**
- 点击拾取（Raycaster）
- 拖拽旋转、滚轮缩放
- "只显示某系统/某部件"的过滤开关
- 透明度调节（看内部）

**坑**
- 部件互相穿插、层级不清
- 标签重叠（需做避让或只显示选中项）
- 比例失真却没有"非真实比例"声明

## 3. 实验 / 模拟型

**代表**：质壁分离、酶活性影响因素、遗传杂交、探究酵母菌呼吸方式

**必备**
- 自变量滑杆（浓度、温度、pH、时间等）
- 因变量读数（实时数字 + 曲线）
- 对照组 / 实验组切换
- 实验步骤条（当前步骤高亮）
- 结论区（随结果变化，不能写死）

**交互**
- 滑杆实时驱动 3D 与曲线
- "开始/暂停/重置"实验
- 记录数据点（可清空）
- 异常条件给出提示（如高温使酶失活）

**坑**
- 曲线是贴图/写死的，不随参数变
- 没有对照组概念
- 结论与数据矛盾
- 编造"标准实验数据"

## 4. 对比型

**代表**：有丝分裂 vs 减数分裂、光合 vs 呼吸、DNA 复制 vs 转录

**必备**
- 左右双场景（或上下），共享相机操作
- 同步时间轴 / 同步阶段
- 差异高亮（只标不同点，不整体变色）
- 对比表格（右侧面板，随阶段高亮当前行）
- 各自独立的数量读数

**交互**
- 同步 / 独立 两种模式
- 点击差异项 → 两侧同时定位
- 一键"只看差异"

**坑**
- 两侧阶段数不同却强行同步（需做映射）
- 差异用整体变色表达，学生抓不住重点
- 对比表与画面数字不一致

## 通用取舍

- **不要为了 3D 而 3D**：看不见的内部结构才值得 3D；纯流程用时间轴即可
- **一屏一个核心问题**：面板六块已经够满，不要再堆
- **模型程序化生成**：不依赖外部 glTF/OBJ，保证单文件离线
- **性能**：像素比上限 2，粒子/实例数量可控，移动端降级
