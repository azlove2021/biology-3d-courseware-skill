# 术语口径与禁用表述

以**人教版 2019**为准。教材 > 教辅 > 网络资料；有争议时先问用户，不自行"折中"。

## 1. 减数分裂 / 遗传

| 概念 | 正确表述 | 常见错误 |
|---|---|---|
| 起点（精子形成） | **初级精母细胞** | 精原细胞（精原细胞是有丝分裂阶段） |
| 起点（卵细胞形成） | **初级卵母细胞** | 卵原细胞 |
| 子细胞（精子） | **精细胞**，需**变形**才成为精子 | 直接说"4 个精子" |
| 子细胞（卵） | 1 个**卵细胞** + 3 个**极体**（不均等分裂） | 说"4 个卵细胞" |
| 同源染色体 | 形状大小一般相同，一条来自父方、一条来自母方；前期Ⅰ**联会** | 说"大小一定相同"（性染色体例外） |
| 姐妹染色单体 | 同一**着丝粒**连接的两条染色单体 | 与"非姐妹染色单体"混用 |
| 四分体 | 1 个四分体 = 1 对同源染色体 = 2 条染色体 = 4 条染色单体 = 4 个 DNA | 说"4 条染色体" |
| 交叉互换 | 前期Ⅰ，同源染色体的**非姐妹染色单体**之间 | 说"姐妹染色单体交叉互换" |
| 自由组合 | 后期Ⅰ，**非同源染色体**自由组合 | 说"同源染色体自由组合" |
| 着丝粒 | 人教版 2019 用**着丝粒** | 着丝点（旧教材） |
| 赤道板 | 是一个**位置**，不是真实结构 | 画成一块板/说"细胞板" |
| 后期Ⅰ | 同源染色体分离，**着丝粒不分裂** | 说着丝粒分裂 |
| 后期Ⅱ | **着丝粒分裂**，姐妹染色单体分开 | 说同源染色体分离 |
| 中期Ⅰ | 同源染色体**成对排列在赤道板两侧** | 说"排列在赤道板上" |

## 2. 光合作用 / 细胞呼吸

- **总光合速率 = 净光合速率 + 呼吸速率**；题目说"吸收 CO₂"通常指净光合
- 光补偿点：光合 = 呼吸；光饱和点：再增光强光合不再增
- 有氧呼吸三阶段场所：**细胞质基质 → 线粒体基质 → 线粒体内膜**
- 无氧呼吸全过程在**细胞质基质**
- 叶绿体：**类囊体薄膜**（光反应）与**基质**（暗反应），不要写"叶绿体基质中进行光反应"
- 净光合"释放 O₂"、总光合"产生 O₂"要分清

## 3. 细胞结构与物质运输

- 原核细胞：**没有核膜包被的细胞核**（不是"没有细胞核"）
- 细胞器名称：线粒体、叶绿体、内质网、高尔基体、溶酶体、核糖体、中心体、液泡
- 植物细胞壁主要成分：纤维素和果胶；动物细胞无细胞壁
- 质壁分离中的"**原生质层**"= 细胞膜 + 液泡膜 + 两层膜之间的细胞质；不是"原生质体"
- 跨膜运输：自由扩散、协助扩散、主动运输；大分子用胞吞/胞吐
- **细胞液**指液泡内的液体；**细胞质基质**是细胞质中除细胞器外的部分，二者不同

## 4. 稳态与调节

- 内环境 = 血浆 + 组织液 + 淋巴（淋巴液）
- 反射弧五环节：感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器
- 兴奋在神经纤维上**双向**传导，在突触处**单向**传递
- 激素调节特点：分级调节、反馈调节（负反馈为主）
- 特异性免疫：体液免疫（B 细胞/抗体）与细胞免疫（T 细胞）

## 5. 生态

- 种群数量特征：种群密度、出生率/死亡率、迁入率/迁出率、年龄结构、性别比例
- 种间关系：竞争、捕食、寄生、互利共生
- 生态系统组成成分：非生物的物质和能量、生产者、消费者、分解者
- 能量流动：**单向流动、逐级递减**（相邻营养级传递效率 10%~20%）
- 物质循环：**全球性、循环往复**

## 6. 通用表述规则

1. 凡出现数字，必须同时给**统计口径**（每个细胞 / 每个子细胞 / 每个正在分裂的细胞）
2. 凡出现 3D 模型，必须标「**示意 · 非真实比例**」
3. 凡用颜色区分，必须注明「**颜色仅用于区分来源/结构，非真实颜色**」
4. 不编造显微尺寸、放大倍数、实验数据、页码
5. 不把"教材没讲的推论"写成结论；不确定就标注"拓展"

## 7. 禁用表述速查

| 禁用 | 改为 |
|---|---|
| 精原细胞（减数分裂起点） | 初级精母细胞 |
| 着丝点 | 着丝粒 |
| 原生质体（质壁分离） | 原生质层 |
| 染色体复制后数目加倍 | 染色体数目不变，DNA 加倍 |
| 减数分裂产生 4 个精子 | 产生 4 个精细胞，变形后成为精子 |
| 同源染色体排列在赤道板上 | 同源染色体成对排列在赤道板两侧 |
| 后期Ⅱ 同源染色体分离 | 后期Ⅱ 着丝粒分裂，姐妹染色单体分开 |
| 姐妹染色单体交叉互换 | 非姐妹染色单体交叉互换 |
