# 本地知识库配置

## 1. 原则

公开技能里**不写死作者本机路径**。知识库位置属于本地配置，谁用谁配。

## 2. 配置方式

优先级从高到低：

1. 用户在本次对话中直接提供的材料（教材截图、讲义、文档）
2. 环境变量 `BIOLOGY_KB` 指向的目录
3. `courseware-profile.json` 的 `knowledgeBase` 字段
4. 经核实的公开资料（人教版教材目录、官方教参）

示例：

```json
{
  "knowledgeBase": "D:/我的资料/高中生物知识库"
}
```

```bash
# Windows PowerShell
$env:BIOLOGY_KB = "D:/我的资料/高中生物知识库"
# macOS / Linux
export BIOLOGY_KB="/Users/me/biology-kb"
```

## 3. 取材顺序

在知识库目录中优先找：

1. `00-知识梳理与课件规划/高中生物知识库全景梳理.md`
2. 同目录的 `高中生物3D课件点子计划表.md`
3. 对应章节的讲义、教材扫描、实验清单

## 4. 路径不存在时怎么办

- **不要**因为路径不存在就编造教材依据、页码、实验数据
- 用用户本次提供的材料，或明确标注"待核实"
- 存在实质性知识分歧时，列出待确认项，请用户拍板
- 简单、可自行判断的格式问题，不要中断任务去问

## 5. 交付时写什么

- 教材依据写到**小节级**（如 `必修2 第2章第1节`）
- 不写页码，除非用户明确提供且可核对
- 无法核实的结论标"拓展"或"待核实"，不要伪装成教材原话
