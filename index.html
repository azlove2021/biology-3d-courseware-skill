QUALITY GATES

六道门槛，保证「好看」不是唯一标准

DATA

单一数据源

阶段 JSON 同时驱动 3D、读数、曲线和 README；图表写死会被校验脚本拦住。

VOICE

语音五态

pending / speaking / ended / cancelled / error，token 防串台；只有当前段正常结束才进下一步。

CHECK

三层校验

静态结构 / 数据一致性 / 浏览器运行；12 个故障样例证明脚本能抓真错。

OFFLINE

离线单文件

three.js 内联，零外链；断网后 canvas 仍正常，投影、电子白板都能用。

SCIENCE

人教版口径

每步标教材小节；示意声明写清简化；术语表拦住「精原细胞 / 着丝点」这类旧表述。

PUBLISH

发布有授权

默认只落本地；公开仓库 / Pages 前扫描敏感信息，私有仓库不擅自改公开。
